## Como enviar

1. Baixe o arquivo `temakeria-site-pronto.zip` entregue nesta conversa.
2. Extraia o ZIP e abra a pasta `assets` no seu computador.
3. No GitHub, abra a pasta `assets` deste repositório.
4. Clique em **Add file → Upload files**, arraste os nove arquivos WEBP e clique em **Commit changes**.
5. Confira **Settings → Pages** para garantir que a publicação na branch `main`, pasta `/(root)`, está ativa.

O HTML contém imagens demonstrativas para situações em que as fotos originais ainda não foram enviadas; não confunda essas imagens com produtos reais da Temakeria.
